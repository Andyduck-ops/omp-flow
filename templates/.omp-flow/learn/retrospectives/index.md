# Learning retrospectives

Retrospective bundles reflect on a substantive change, problem, or lesson in technical
understanding, human digestion, Agent explanations or assumptions, or the way the participants
collaborate. Create one only when reflection itself will help a later encounter; do not create one
to complete a companion set.

Name a warranted bundle `YYYY-MM-DD-<topic>/` and give it an authored `index.md` for resumption,
with optional descriptive Markdown Concepts when useful. A Daily may stand alone without a
Retrospective. This index supports discovery rather than an exhaustive inventory or completion
record.
