# Cross-encounter learning threads

Thread bundles preserve continuity only when a topic genuinely spans encounters. They can maintain
the current shared model, a live disagreement or unresolved question, and useful ordinary links to
the Daily encounters that changed the topic.

Name a warranted bundle `YYYY-MM-DD-<topic>/` and maintain an authored `index.md` for resumption,
with optional descriptive Markdown Concepts only when useful. A Daily does not require a Thread,
and a Thread is not a task, dependency graph, or learning lifecycle. This index aids navigation and
is not an exhaustive manifest.
