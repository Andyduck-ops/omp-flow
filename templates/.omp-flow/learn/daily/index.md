# Daily learning encounters

Daily bundles preserve a useful, resumable checkpoint from one real dated Human–Agent co-learning
encounter: its discussion, challenge, examples, corrections, current understanding, or open point.
Create one only when the encounter benefits from preservation.

Name a bundle `YYYY-MM-DD-<topic>/` and give it an authored `index.md` that orients a returning human
and Agent. Add only descriptive Markdown Concepts warranted by the encounter. A Daily may stand
alone; it never requires a Thread or Retrospective companion. This index aids navigation and need
not exhaustively list every bundle.
