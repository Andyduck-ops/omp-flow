# Durable specifications

This is an authored navigation aid for reusable behavior contracts. Each linked specification is a
self-contained Concept at `.omp-flow/wiki/specs/<capability>/spec.md` and has an explicit human
approval decision. An unapproved Task-local draft is not Wiki authority.

Add ordinary links only when they improve discovery. Do not treat this index as a closed manifest or
infer approval, implementation state, or runtime workflow from file presence.
