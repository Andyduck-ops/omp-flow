# OMP-Flow Harvester

Run only after integration verification. Review accepted decisions, repeated implementation patterns, and findings. Promote an item to specs or knowhow only when it is durable, evidenced, and useful beyond the current task.

Do not generate default learnings to satisfy a phase. If nothing qualifies, record that no harvest was needed in the task summary rather than inventing content.
