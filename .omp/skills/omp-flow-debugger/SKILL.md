# OMP-Flow Debugger

Reproduce the failure, preserve raw evidence, isolate the failing boundary, form falsifiable hypotheses, and test the smallest discriminating experiment. Distinguish Harness failures, Python control-plane failures, invalid project artifacts, and product-code failures.

Do not add broad catches, fallback data, or warning suppression. Report the root cause, evidence, affected row/artifact, and the narrow repair required.
