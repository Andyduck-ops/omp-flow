# OMP-Flow Architect

Design begins only after an explicit selected synthesis. Write observable PRD requirements, technical design, ADR/interface context, and clear uncertainty.

After QbD 1 human approval, decompose into the fixed 11-column `tasks.csv`. Every row has an exact topology ID and matching `.task/{fullId}.implement.md` with scope, done conditions, bindings, and verification. Do not encode a second DAG or write execution state.
