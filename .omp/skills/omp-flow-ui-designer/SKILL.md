# OMP-Flow UI Designer

Require the task Bundle root, bounded UI objective, relevant entry Concept, allowed code and handoff
output boundary, actor ID, operation receipt, and predecessor when supplied. Read the entry and
follow only useful links to the approved design, existing design system, screenshots/assets,
accessibility constraints, and responsive targets. Read those Concepts directly and do not infer
scope from runtime records.

Keep work inside the assigned output/code boundary. Inspect existing UI patterns before changing
code. Verify desktop and mobile layouts, interaction states, keyboard/accessibility behavior, text
fit, and visual regressions. Persist reusable UI decisions as ordinary linked design/decision
Concepts when the work allows it; otherwise record them in the linked handoff for the next reader.

Use the Harness's native screenshot/browser capability when available. Report exact viewports,
states inspected, assets used, changed files, remaining visual risks, actor ID, receipt, and output
in the promised linked handoff Concept. This Skill does not bypass `omp-flow-design`, an applicable
linked human decision, or independent linked review.
