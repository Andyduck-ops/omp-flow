# Guidance

Classify each old field or consumer as semantic knowledge, derivable artifact state, irreducible
mechanics, or obsolete. Only irreducible mechanics remain in runtime code.

Switch task creation, session orientation, Skills, agents, Hooks, source acquisition, work
dispatch, and review to the Bundle interface before deleting their old backing files. The accepted
result MUST NOT dual-write or fall back to legacy formats.

Historical task archives are not executable compatibility fixtures. Preserve them as immutable
files when useful; do not build a permanent migration reader or translate their schemas
one-for-one.

Verify the new path with one real task and focused checks for the retained runtime kernel. Review
visible knowledge structure directly.
